# Licensing decision

Selected license: **GNU AGPL version 3 or later**, SPDX `AGPL-3.0-or-later`. The full license is in [LICENSE](../LICENSE).

This preserves the existing application's license. The PDF pipeline now uses MIT/BSD/Apache components; removing its former engine does not itself change the application license. It permits commercial use, paid hosting, installation, and support; it is not a noncommercial restriction and does not prevent competing services.

Distribution carries corresponding-source and notice obligations. Modified network-accessible versions must offer their users the corresponding source as required by section 13. A private GitHub repository does not exempt software delivered to customers or used as a covered service. Source may need to be supplied to recipients/users even when development happens privately.

No proprietary license or commercial dependency entitlement is granted by this repository split. Closed-source distribution would require reviewing ownership/contributor permissions and all dependency obligations; Artifex offers commercial PDF-library licensing. Already granted open-source rights to published versions are not revoked by moving repositories.

The source-offer URL must identify the code actually deployed. A private GitHub URL inaccessible to service users is not an adequate source delivery mechanism for those users. Use an accessible exact source archive or another compliant delivery method.

References: [GNU AGPL rationale](https://www.gnu.org/licenses/why-affero-gpl.html), [GNU license FAQ](https://www.gnu.org/licenses/gpl-faq.en.html), and [PyMuPDF licensing](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright). Obtain qualified review before a proprietary licensing change or public commercial launch.
